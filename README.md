## Projects

### Tri-Branch Fusion CNN: Oral Cancer Screening
**Leak-controlled benchmark AUC ≈ 0.64–0.67.** The default edge candidate, a Dual-Stream Tiny CNN, scores AUC 0.642 ± 0.002. I'm still refining this result; it isn't a final number.

My capstone (BAI685): non-invasive oral cancer screening that pairs autofluorescence imaging (AFI) with edge AI. It fuses three branches (a WLI RGB CNN, an AFI grayscale CNN and a metadata MLP) and targets sub-200 ms INT8 TFLite inference on an ESP32-S3.

[Repository](https://github.com/Pranjal1342/Oral_Sense)

### Agentic SRE OpenEnv
**A reinforcement learning environment that drops agents into simulated production incidents and scores their response the way an on-call rotation would judge a human.**

The policy model is GLM-5.2 (open-weight). It uses hybrid memory (pgvector plus a Postgres causal graph), tools wrapped in MCP, and a ToRA-style planning loop.

[GitHub](https://github.com/Pranjal1342/Agentic_SRE) · [Hugging Face](https://huggingface.co/LordofMonarchs/Agentic_SRE)
